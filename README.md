# Noush's Birthday Cake

**Try it:** open `dist/index.html` from a local server (`python3 -m http.server` in `dist/`, then visit http://localhost:8000). The mic needs https or localhost.

**Her link:** host `dist/index.html` on GitHub Pages and send her `https://<you>.github.io/<repo>/`.

**Your watch link:** the same URL with `?watch` on the end. She never sees it. Open it on your laptop before she starts. It shows her camera, her finger, every step, and a "she paid with a kiss" banner.

**Edit the personal bits:** the `CONFIG` block at the top of `src/app.js`. After any change, run `python3 build.py`.
